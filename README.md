# Клёв — журнал рыбалки

Веб-приложение (PWA) для телефона и компьютера: карта мест, погода с давлением и ветром, метки с погодой за неделю, отчёты о рыбалке с фото.

## Что умеет

- **Карта** — схема (OpenStreetMap) и спутник (Esri), поиск водоёма, посёлка или координат, кнопка «Где я».
- **Погода в любой точке** — коснитесь карты: давление в мм рт. ст. с барометром и тенденцией (за сутки, прогноз на сутки), график давления за 7 дней назад и на 3 дня вперёд, ветер (скорость, порывы, направление), температура, облачность, осадки, влажность, фаза луны, восход и закат, прогноз на 7 дней.
- **«Метка здесь»** — ставит метку там, где вы стоите. К метке сохраняется погода за неделю до её установки, название водоёма подставляется само.
- **Отчёт о рыбалке** — дата, время «с/по» (ночные рыбалки через полночь учитываются), рыба (вид, штук, кг), на что ловилось, способ ловли, глубина, описание, фото. Погода за часы рыбалки и давление за неделю до неё прикрепляются автоматически, в том числе для старых дат (из архива).
- **Без связи на водоёме** — отчёт сохранится сразу, погода подтянется, когда появится интернет. Приложение открывается без сети, уже просмотренные участки карты тоже.
- **Глубины** — кнопка «Глубины» справа на карте включает карту глубин поверх спутника (сейчас — Дон у Рогожкино, около 2 км русла). Слой перекрашен в шкалу с отдельным цветом на каждые 0,5 м, легенда — в панели. При нажатии на точку внутри участка карточка показывает «Глубина ≈ 6–6,5 м» (даже если слой выключен), а в отчёте подсказывает глубину места. Ползунок меняет видимость слоя, «Подвинуть» — ручная подгонка. Работает без интернета.
- **Журнал** — все рыбалки по месяцам, поиск по рыбе, приманке и месту, итоги и подсказки («лучше всего работает…», «с уловом вы были при давлении …»).
- **Резервная копия** — все данные с фото в один файл и восстановление из него.

Данные хранятся только на устройстве, в браузере. Регистрация и серверы не нужны.

## Как выложить в интернет

Геопозиция в браузерах работает только по HTTPS, поэтому приложение нужно разместить на любом хостинге с HTTPS. Это бесплатно и занимает несколько минут. Загружать нужно **содержимое папки `klev`** целиком.

**Вариант 1 — Netlify Drop (проще всего).**
1. Откройте https://app.netlify.com/drop и войдите (бесплатно, можно через Google или почту).
2. Перетащите папку `klev` в окно.
3. Получите адрес вида `https://ваше-имя.netlify.app`. В настройках сайта можно поменять имя.

**Вариант 2 — GitHub Pages.** Создайте репозиторий, загрузите файлы через «Add file → Upload files», затем Settings → Pages → Deploy from a branch → `main` / root. Адрес: `https://логин.github.io/репозиторий/`.

**Если сайт не открывается с российского мобильного интернета** — зарубежные хостинги иногда работают с перебоями. Подойдёт любой российский хостинг с HTTPS, куда можно загрузить файлы (например, статический сайт в Yandex Cloud Object Storage или обычный виртуальный хостинг): просто положите файлы в корень сайта.

## Как открыть на компьютере без хостинга (Windows)

1. Распакуйте архив — получится папка `klev`.
2. Дважды щёлкните `start.bat`. Если Windows спросит «Запустить этот файл?» — нажмите «Запустить» (или «Подробнее» → «Выполнить в любом случае»).
3. Откроется браузер с адресом http://localhost:8000. Чёрное окно не закрывайте, пока пользуетесь приложением.

Просто дважды щёлкнуть `index.html` не получится: браузер не запускает такие приложения из файла.

Есть Python — можно и так: в папке `klev` выполните `python -m http.server 8000` и откройте http://localhost:8000.

Записи, сделанные на компьютере, хранятся в браузере компьютера. Перенести их на телефон можно через «Сохранить копию» → «Восстановить из файла». Геопозиция на компьютере обычно приблизительная (по Wi-Fi), для меток на берегу нужен телефон, а для телефона — хостинг.

## Как установить на телефон

- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран „Домой“».

При первом нажатии «Метка здесь» или «Где я» разрешите доступ к геопозиции.

## Данные и резервная копия

Всё хранится в браузере на телефоне. Если очистить данные браузера или удалить приложение, записи пропадут, поэтому периодически делайте копию: Журнал → шестерёнка → «Сохранить копию». На новом телефоне: «Восстановить из файла».

## Источники данных

- Погода — [Open-Meteo](https://open-meteo.com/) (бесплатно, без ключа): на ближайшие 3 дня модель ICON (DWD), дальше — ECMWF. Давление — на уровне местности, как на бытовом барометре.
- Нагон и сгон (дельта Дона, Таганрогский залив) — оценка по ветру за сутки: низовка с запада-юго-запада гонит воду, верховка с востока-северо-востока сгоняет. Это подсказка, а не замер уровня.
- Карта — © участники OpenStreetMap; спутниковые снимки — Esri.
- Поиск и названия мест — Nominatim (OpenStreetMap).
- Фаза луны считается на устройстве.

## Для разработчика

Чистый HTML/CSS/JS без сборки и зависимостей.

```
index.html            разметка
start.bat, server.ps1 запуск на компьютере с Windows без хостинга
css/app.css           стили (светлая и тёмная тема)
js/app.js             запуск, маршруты (#map, #spots, #journal, #spot-…, #report-…), геопозиция, шторка
js/map.js             собственный движок карты (тайлы, жесты, метки, картинка-слой)
js/depth.js           список слоёв глубин и их координаты
depth/                картинки слоёв глубин (в трёх размерах для разных масштабов)
js/views.js           экраны: погода, место, отчёт, форма, журнал, настройки
js/store.js           данные, фото, поиск мест, резервная копия, догрузка погоды
js/weather.js         Open-Meteo, давление и тенденция, луна, коды погоды
js/charts.js          графики, барометр, значок луны
js/db.js              IndexedDB
sw.js                 офлайн-кэш (при обновлении файлов поменяйте VERSION)
manifest.webmanifest  установка как приложения
```

## Как добавить новый участок глубин

Пришлите в чат скриншоты карты глубин (севером вверх, одинаковое приближение, с перекрытием) и координаты двух заметных точек на этом участке — их можно взять в Яндекс Картах правой кнопкой → «Что здесь?». Скриншоты склеиваются в одну картинку, суша вырезается, и слой добавляется в `js/depth.js`.
